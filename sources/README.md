# Luna NG corresponding source

The file [script.luna.ng-2.7.1.280-source.tar.gz](script.luna.ng-2.7.1.280-source.tar.gz) is the GPLv3 corresponding source archive for the CoreELEC 21 NG ARM32 add-on [script.luna.ng-2.7.1.280.zip](../script.luna.ng/script.luna.ng-2.7.1.280.zip).

It includes the pinned Luna Python launcher source, Moonlight Embedded C source with required submodules, and CoreELEC NG build recipes. The editable Git development history remains private; this matching source is offered to recipients at no charge.
